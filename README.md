# Networking Fundamentals

## About This Repository

This repository documents my learning journey in computer networking through the **Ağ Temelleri** training at BTK Akademi.

It includes structured technical notes, a course report, and a practical networking lab developed using Cisco Packet Tracer.

## Topics Covered

- Network Fundamentals and Topologies
- OSI and TCP/IP Models
- Ethernet, MAC Addresses, and Network Devices
- IPv4, IPv6, and Subnetting
- DHCP, DNS, TCP, and UDP
- Routing and Switching
- Wireless Networking
- Network Security
- Cloud Computing and Virtualization
- Network Troubleshooting

## Practical Lab

**Routing Between Two LANs — Cisco Packet Tracer**

The lab connects two IPv4 networks through a router:

- LAN 1: `192.168.10.0/24`
- LAN 2: `192.168.20.0/24`

Communication between devices on the two networks was tested successfully using ping.
